What it does

Feed it a PDF invoice. Get back structured fields:

vendor

Vendor name extracted from the invoice.

invoice_number

Invoice or receipt number.

invoice_date

Invoice date (YYYY-MM-DD).

total + currency

Total amount and currency (USD, EUR, GBP).

vat_number

VAT or tax ID number.

How it works

$ echo '{"pdf_path":"/path/to/invoice.pdf"}' | python extract.py
{"vendor": "Acme Corp", "invoice_number": "INV-2026-001", "invoice_date": "2026-01-15", "total": 1200.0, "currency": "USD", "vat_number": null, "line_items": []}

PyPDF2 for text extraction, deterministic regex for field parsing. No model, no API call, no data leaves your machine.

Why deterministic

An LLM extracting invoice fields is a black box you cannot audit.
